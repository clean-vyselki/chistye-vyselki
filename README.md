# Чистые Выселки

Статический сайт сообщества «Чистые Выселки» — жителей станицы Выселки, которые очищают станицу от мусора.

Сайт полностью статичный (HTML/CSS/JS без фреймворков) и подходит для публикации на GitHub Pages.

## Возможности

- Главная страница с hero-блоком и статистикой
- Раздел «Прошедшие рейды» с фото, описанием, тегами, числом участников и мешков
- Раздел «Предстоящие рейды» с датой, временем и местом встречи
- Форма подачи жалобы: имя, улица и номер, описание проблемы, фото (по желанию)
- Раздел «О сообществе»
- Админ-панель по адресу `/admin` (логин `admin`, пароль `bear123`)
  - Добавление / редактирование / удаление рейдов
  - Управление будущими рейдами
  - Просмотр жалоб и смена их статуса
  - Экспорт и импорт данных в JSON
  - Сброс к демо-данным

## Логотип

В шапке и подвале сайта есть место под `logo.png` в корне проекта. Просто положите свой `logo.png` в корень — он автоматически появится на месте заглушки.

## Где хранятся данные

Сайт статический, поэтому данные хранятся в `localStorage` браузера:

- Рейды и жалобы, добавленные через админ-панель, видны только в том браузере, где их добавили.
- Чтобы сделать новые рейды видимыми для всех посетителей, используйте раздел **Экспорт / Импорт** в админ-панели:
  1. Добавьте рейды через админку.
  2. Нажмите «Скачать raids.json».
  3. Скопируйте содержимое файла в массив `CV.DEFAULT_RAIDS` в `js/data.js`.
  4. Сделайте commit и push в репозиторий.

Жалобы — обратная связь от посетителей, они накапливаются в браузере администратора. Регулярно экспортируйте их в архив.

## Деплой на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `chistye-vyselki`).
2. Загрузите все файлы из папки проекта в корень репозитория.
3. Загрузите свой `logo.png` в корень репозитория.
4. В настройках репозитория откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Deploy from a branch**.
6. Выберите ветку `main` и папку `/ (root)`.
7. Нажмите **Save**.
8. Через 1–2 минуты сайт будет доступен по адресу:

   ```
   https://<ваш-username>.github.io/chistye-vyselki/
   ```

Админ-панель будет доступна по адресу:

```
https://<ваш-username>.github.io/chistye-vyselki/admin/
```

## Учётные данные администратора

- Логин: `admin`
- Пароль: `bear123`

Хранятся прямо в коде (`js/admin.js`). Это не безопасно для публичного доступа — любой может посмотреть исходный код. Для реальной защиты нужен сервер с аутентификацией, но для статического GitHub Pages такой вариант приемлем, если пароль периодически меняется и доступ к админке нужен только для управления контентом.

## Смена пароля

Откройте `js/admin.js` и измените строки:

```
const ADMIN_USER = "admin";
const ADMIN_PASS = "bear123";
```

## Локальный запуск

Можно просто открыть `index.html` в браузере. Но для корректной работы админ-панели (sessionStorage и fetch) лучше запустить локальный сервер:

```bash
cd chistye-vyselki
python3 -m http.server 8000
```

Откройте `http://localhost:8000` в браузере.
